**Simulating massive intelligent biological systems at the hardware level.**

`axiom_swarm_ai` is a high-performance Swarm Intelligence (Flocking Behavior) engine core written in pure **Rust**. It utilizes a highly optimized implementation of Craig Reynolds' algorithmic rules (Separation, Alignment, and Cohesion), completely parallelized to execute across all available CPU threads simultaneously.

No heavy architectures, no object-oriented overhead. **Just 15,000+ autonomous brains acting as a single sovereign entity.**

---

## ⚡ Technical Superpowers

* **🦅 Multithreaded Brain-Loops:** Powered by `rayon`, every single agent calculates its visual vectors, neighbor positions, and collision avoidance formulas in parallel, maximizing multi-core CPUs.
* **🪐 Kinetic Fluidity:** Simulates **15,000+ intelligent entities** rendering fluidly at maximum framerates without memory garbage collection.
* **🔮 Data Realignment:** Designed to be easily integrated as a navigation/AI core for space simulators, RTS hordes, or biological cell simulations.

## 🚀 Deployment (Run in 5 Seconds)

1. **Clone the arsenal:**
   ```bash
   git clone [https://github.com/echeparesmanuel36-design/axiom_swarm_ai.git](https://github.com/echeparesmanuel36-design/axiom_swarm_ai.git)
   cd axiom_swarm_ai
   ```
2. **Ignite the engine:**
```bash
cargo run --release
```
